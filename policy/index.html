한국어 MCU 안내

공개 검토를 거친 파생 안내만 제공합니다. 문서별 보드·칩·SDK 판본과 고정 원출처를 확인하세요. 펌웨어 빌드와 실기 시험은 수행하지 않았습니다. 전체 임베디드 원문 도서관은 공개 범위가 아닙니다.

출처·고지·시각 자산

각 안내의 출처·라이선스 전문을 따릅니다. 사이트 열람이 모든 원자료의 재배포나 AI 학습 허가를 뜻하지 않습니다. 원제조사와 제휴·인증 관계를 주장하지 않습니다. 로고는 운영자가 제공한 자산이고 배경은 생성형 이미지로 만든 장식입니다. 별도 일반 재사용 허가는 부여하지 않습니다.

운영과 정정

운영 계정: IDTenev · Mist Atelier 공개 프리뷰. 오류·출처·권리 정정은 공개 GitHub Issues에 문서 주소와 근거를 남겨 주세요. 비밀번호·개인정보·사내 자료는 공개 이슈에 올리지 마세요. 정정과 철회가 과거 Git 이력·타인의 복사본·호스팅 캐시까지 즉시 삭제하는 것은 아닙니다.

데이터 처리

GitHub Pages에서 정적 파일을 제공합니다. 사이트 자체의 광고·분석 스크립트, 쿠키·브라우저 저장소, 회원가입·문의 전송 기능은 없습니다. 검색은 브라우저에서 처리합니다. 검색어가 주소에 표시되면 방문 기록·주소 공유에 포함되며 해당 주소를 다시 요청할 때 호스팅 서비스로 전달될 수 있습니다.

GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록합니다. 호스팅과 이슈 작성에는 GitHub 개인정보 처리방침이 적용됩니다. 외부 출처 링크를 열면 해당 사이트 정책이 적용됩니다.

공개 범위와 한계

한국어 이용자를 우선하며 국가 차단은 없습니다. 별도 도메인·광고는 연결하지 않았습니다. HTML에는 검색엔진 색인 제외 요청을 넣지만 이는 로그인이나 접근 보호가 아닙니다. 공개 파일과 저장소는 누구나 볼 수 있습니다.
