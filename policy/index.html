출처·고지·시각 자산

각 안내의 출처·라이선스 전문을 따릅니다. 사이트 열람이 모든 원자료의 재배포나 AI 학습 허가를 뜻하지 않습니다. 원제조사와 제휴·인증 관계를 주장하지 않습니다. 로고는 운영자가 제공한 자산이고 배경은 생성형 이미지로 만든 장식입니다. 별도 일반 재사용 허가는 부여하지 않습니다.

운영과 정정

운영 계정: IDTenev · Mist Atelier 공개 프리뷰. 오류·출처·권리 정정은 공개 GitHub Issues에 문서 주소와 근거를 남겨 주세요. 비밀번호·개인정보·사내 자료는 공개 이슈에 올리지 마세요. 정정과 철회가 과거 Git 이력·타인의 복사본·호스팅 캐시까지 즉시 삭제하는 것은 아닙니다.

데이터 처리

GitHub Pages에서 정적 파일을 제공합니다. 광고·외부 실행 분석 스크립트·쿠키·브라우저 저장소·회원가입은 사용하지 않습니다. 아래 조회수·자료 열람 집계만 수행합니다. 검색은 브라우저에서 처리합니다. 검색어가 주소에 표시되면 방문 기록·주소 공유에 포함되며 해당 주소를 다시 요청할 때 호스팅 서비스로 전달될 수 있습니다.

GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록합니다. 호스팅과 이슈 작성에는 GitHub 개인정보 처리방침이 적용됩니다. 외부 출처 링크를 열면 해당 사이트 정책이 적용됩니다.

공개 범위와 한계

한국어 이용자를 우선하며 국가 차단은 없습니다. 별도 도메인·광고는 연결하지 않았습니다. HTML에는 검색엔진 색인 제외 요청을 넣지만 이는 로그인이나 접근 보호가 아닙니다. 공개 파일과 저장소는 누구나 볼 수 있습니다.

사이트 누적 조회수

상단 조회수는 기존 사이트 공통 Hits 키를 그대로 사용합니다. 공개 페이지가 화면에 보일 때 배지를 한 번 요청하며 메인·검색·목록·통계 방문도 포함합니다. 버전업·재배포로 키를 바꾸거나 값을 초기화하지 않습니다. 자료 열람 통계로 표시했던 기간의 페이지 조회는 소급해 더하지 않습니다.

자료 열람 집계

자료 본문을 정상 표시한 뒤 자료별 Hits 배지 요청 1회를 별도로 보냅니다. 검색·목록·통계 화면, 직접 다운로드는 자료 열람으로 집계하지 않습니다. 두 지표 모두 고유 방문자나 독서 완료 수가 아니며 캐시·차단·자동 요청과 장애의 영향을 받습니다. 기존 전체 페이지 조회수는 새 자료 열람 통계에 합치지 않습니다.

Hits에는 고정 사이트 키 또는 자료 ID를 SHA-256으로 변환한 공개 카운터 키와 통상 접속 정보가 전달될 수 있습니다. 검색어·원문 경로·방문자 ID는 집계 URL에 넣지 않으며 쿠키·브라우저 저장소·외부 실행 스크립트는 사용하지 않습니다. 공개 자료와 카운터의 대응은 익명성이나 접근 통제를 보장하지 않습니다. 상세 통계는 증가 없는 API로 수집한 배포 시점 자료이며, 미집계·일부 확인을 0이나 전체 합계로 표시하지 않습니다. 집계 기준과 전체 통계 · Hits 개인정보 처리 · 서비스 조건
