# 이동 평균·EMA · 부드러움과 지연의 교환

검토: 2026-09-20 · 분류: 구현 패턴 / 센서·제어 / 신호 처리 패턴

별칭: Moving Average, Boxcar FIR, EMA, Exponential Smoothing

적용 분야: 센서 표시, 측정 추세, 지표 평활

## 개념과 특징

이동 평균은 최근 N개 샘플을 동일 가중치로 평균한다. EMA는 y += alpha×(x-y)로 과거를 점점 적게 반영한다. 잡음을 줄이지만 실제 변화도 늦게 보이며 이상치에 강한 필터와는 다르다.

## 구조와 동작

유효 샘플/시각 → 오래된 값 제거·누적합 갱신 또는 EMA 갱신 → 평활 값 + 유효 상태

## 언제 쓰고 피할까

- 사용: 작은 랜덤 변동을 줄여 표시나 느린 상태 판단을 안정화하고 지연을 허용할 때.
- 비추천: 짧은 위험 peak를 놓치면 안 되는 보호 경로, 샘플링 이전 aliasing을 소프트웨어 평균으로 해결하려는 경우.

## 장점과 비용

- 장점: 이동 평균은 순환 배열·누적합으로 샘플당 O(1), EMA는 O(1) 메모리로 구현할 수 있다.
- 단점·비용: 이동 평균은 O(N) 메모리와 지연을 가진다. EMA는 초기화와 샘플 주기 변화에 민감하다. 정수 누적 overflow·반올림 누적에 주의해야 한다.

## 설계·구현 가이드

1. 샘플 주기와 허용 지연을 정한다. 균일 샘플 N점 평균의 선형 위상 group delay는 (N-1)/2 샘플이다.
2. 초기 N개가 차기 전에는 현재 유효 개수로 나누거나 warming 상태로 명시한다. 0으로 채운 값을 실제 측정처럼 섞지 않는다.
3. 누적합 타입에 N×최대값 여유를 두고 invalid/누락 처리 정책을 정한다.
4. EMA의 alpha는 0<alpha<=1로 검사한다. 불규칙 주기에서 시간 상수를 유지하려면 dt 기반 계수를 설계·검증한다.

## 적용 예시

100 Hz에서 11점 평균의 group delay는 50 ms다. 표시에는 괜찮아도 10 ms 이내 보호 동작에는 맞지 않는다. EMA alpha=0.2, 초기값 0, 일정 입력 10이면 출력은 2→3.6→4.88로 접근한다.

이 절은 구현 결정을 설명하는 설계 사례다. 실행 프로그램이나 장비 설정 파일이 아니다.

## 실패·동시성·종료 조건

NaN 한 번으로 필터 상태 전체가 오염될 수 있다. 센서 fault와 정상값 필터를 분리하고 재연결 때 초기화 규칙을 정한다. 제어 루프에 넣으면 위상 지연이 안정성에 미치는 영향을 다시 평가한다.

## 검증 기준

상수·계단·임펄스·최대/최소·누락 입력을 검사한다. 필터 전후 잡음과 응답 지연을 같이 측정하고 동작 주기 변경 시 다시 평가한다.
